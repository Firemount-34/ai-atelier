# 01 · The Main Avatar — 主形象

**English | [中文](README.zh-CN.md)**

One character, eight outfits. She is the original avatar of the Muse
personal assistant: big-head chibi, long straight black hair with a center
part, pearl earrings, and a signature pose — typing on a small laptop.
Seven outfits rotate weekly as the assistant's avatar (Mon–Sun); the eighth
is a spare. The styles span hanfu, qipao, a pearl dress, a modern suit and
a casual sweater — same character throughout, only the clothes change.
