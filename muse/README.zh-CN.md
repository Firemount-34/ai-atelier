# muse/ — Muse 平台形象

**[English](README.md) | 中文**

这个虚拟形象在 Muse 个人助手里的原始素材：主头像、深色模式状态图，
以及她全套八套服装（一周七天轮换加一套备用），都是同一风格——大头、
上半身、敲电脑造型。
