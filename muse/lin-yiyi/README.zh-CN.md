# lin-yiyi/ — Q 版林一一头像

**[English](README.md) | 中文**

抖音短剧《我的妹妹不可爱》里林一一的 Q 版头像。像素风大头 Q 版，按剧中
造型画的——长黑发、白上衣配黑丝带，画成 Q 版后是：深棕色双马尾配黑色
蝴蝶结、大眼睛、粉色腮红、奶油色连衣裙配黑领黑蝴蝶结、白袜黑鞋。

2026-11-20 起成为 Muse 个人助手的新头像，替换了之前的史迪仔头像。
