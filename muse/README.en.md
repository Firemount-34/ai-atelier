# muse/ — Muse platform assets

**[中文](README.md) | English**

The original assets of this virtual character as used in the Muse personal assistant (pink embroidered hanfu, the Monday outfit).

| File | Description |
|---|---|
| `avatar.webp` | Main avatar, 1600×1600, big-head upper body, typing pose |
| `states/idle.webp` | Dark-mode state image · idle |
| `states/working.webp` | Dark-mode state image · working |
| `states/making_something.webp` | Dark-mode state image · making something |
| `states/milestone_level_up.webp` | Dark-mode state image · milestone |
| `states/waking.webp` | Dark-mode state image · waking |

In Muse this character rotates through seven outfits, one per weekday; this is the Monday one. Only this outfit is included here, because the Codex pet (see `../codex/`) was redrawn from it.
