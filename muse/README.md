# muse/ — Muse platform assets

**English | [中文](README.zh-CN.md)**

The original assets of this virtual character as used in the Muse personal
assistant: the main avatar, dark-mode state images, and her full wardrobe of
eight outfits (a seven-outfit weekly rotation plus one spare), all in the same
big-head, upper-body, typing-on-a-laptop style.

## Main avatar & states (Monday outfit)

| File | Description |
|---|---|
| `avatar.webp` | Main avatar, 1600×1600 — pink embroidered hanfu (Monday) |
| `states/idle.webp` | Dark-mode state image · idle |
| `states/working.webp` | Dark-mode state image · working |
| `states/making_something.webp` | Dark-mode state image · making something |
| `states/milestone_level_up.webp` | Dark-mode state image · milestone |
| `states/waking.webp` | Dark-mode state image · waking |
