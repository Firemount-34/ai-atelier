# muse/ — Muse 平台形象

**中文 | [English](README.en.md)**

这个虚拟形象在 Muse 个人助手里的原始素材（粉白刺绣古装，周一造型）。

| 文件 | 说明 |
|---|---|
| `avatar.webp` | 主头像，1600×1600，大头上半身、敲电脑造型 |
| `states/idle.webp` | 深色模式状态图 · 待机 |
| `states/working.webp` | 深色模式状态图 · 工作中 |
| `states/making_something.webp` | 深色模式状态图 · 制作中 |
| `states/milestone_level_up.webp` | 深色模式状态图 · 里程碑 |
| `states/waking.webp` | 深色模式状态图 · 唤醒 |

该形象在 Muse 里是一周七套服装轮换的周一装；本仓库只收录这一套，
因为 Codex 版伙伴（见 `../codex/`）正是基于这一套重绘的。
