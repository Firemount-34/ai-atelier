# twin-tails/ — Original Twin-Tails Avatar

**English | [中文](README.zh-CN.md)**

A fully original pixel-art chibi character: big-head Q version, long dark-brown
twin tails tied with black bows, large black eyes with pink cheek blush, a cream
dress with a black collar and bow, white socks and black shoes. She is not based
on any existing character or person.
